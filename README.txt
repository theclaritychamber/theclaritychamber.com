# The Clarity Chamber — HTML Website

Standalone static HTML pages for GitHub Pages.

Files:
- index.html — Welcome / homepage
- about.html — About Loveleen
- readings.html — Tarot readings
- process.html — How it works
- faq.html — FAQ
- booking.html — Book a Reading

All styling is embedded in each HTML file, so no external CSS framework is required.
The booking form is front-end only and should be connected to your chosen booking/payment service before launch.
